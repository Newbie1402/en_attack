# SnowGraph game UX specification

Gameplay is a dedicated viewport, not a marketing page. On desktop the battlefield is the dominant center
surface, the unit rail stays compact on the left, and the formula/tactical dock stays within the bottom
viewport band. On narrow screens the bands may stack and scroll; no essential control is hidden.

Player-facing copy must be Vietnamese by default and must not expose raw modes or enum names. Invalid
formula, quota, cooldown, full inventory, victory and defeat each get a direct, recoverable message.

Formula input remains the same bounded parser contract. Preview uses the same sampler as the projectile.
The selected swallow, cooldown, formula history and quota status are visible in the lab surface.

Focus rings, keyboard-safe text input, touch-sized controls and reduced-motion behavior are required for
each visual phase.
