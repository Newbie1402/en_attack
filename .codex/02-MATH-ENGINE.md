# 02 — Math engine contract and trajectory semantics

## Accepted input
Single explicit real scalar function of x, either `0.5x`, `y = 0.5*x` or `f(x)=0.5*x`. Strip at most one anchored optional prefix; trim, normalize supported unicode minus/multiplication only; limit original input length before normalization. Do not accept arbitrary assignment. Radians. Constants `pi`, `e`; only x variable. Operators + - * / ^ and unary +/-; parentheses; math.js implicit multiplication subject to parser semantics and tests. Functions `sin`, `cos`, `tan`, `abs`, `sqrt`, `exp`, `log` (natural, one arg) as level allows. No equation solving, multi-valued functions, complex, matrices, strings, factorial, object access, arbitrary identifiers, units, assignments, function definitions, ranges, comparisons, conditionals, random or user-defined functions. UI must show syntax and precedence examples; `x^2`, not JavaScript XOR. `2x`, `2.0*x`, `x+x` must work.

## Safety and evaluation pipeline
1. Reject >160 UTF-16 code units, >96 lexical tokens, >16 nesting before parse; only ASCII digits/letters/allowed punctuation after normalization; allow scientific notation only if validated as a numeric literal; no square/curly brackets, quotes, semicolon, colon or unapproved characters. Guard long exponent literals and numeric magnitude.
2. Use math.js `parse` only, walk entire AST with <=96 nodes, depth <=16. Explicit allowlist: finite numeric ConstantNode, SymbolNode (x/pi/e), ParenthesisNode, OperatorNode (specific op/function/arity), FunctionNode (direct SymbolNode function name, allowlist, exact arity). Reject everything else, no accessors or blocks. Validate AST even when source looks safe. No `math.evaluate`, `node.evaluate`, `compile`, `eval`, `new Function`, or direct runtime invocation by user-controlled names. Convert allowed AST into tiny immutable internal expression IR; dispatch through explicit switches using Math functions, own bounded evaluator. Evaluate operations only if finite real; cap abs intermediate 1e6 and |exponent|<=32; division by zero, invalid log/sqrt and nonfinite results return invalid sample. Never clamp to fabricate a valid trajectory. Use worker or bounded incremental computation if measurements require it; reject stale worker result by request id.
3. Validate origin: `f(0)` finite and abs <=1e-7. If valid within epsilon, launch at exact origin (numerical tolerance only). Reject e.g. `y=x+2`; explain need to pass (0,0). Do not silently use `f(x)-f(0)`. `cos(x)-1` valid, `cos(x)` not. Require initial viable visible segment (length >=0.25 cells or reaches collision before that only if explicitly supported). Invalid domain later ends flight; no teleport across gaps. Negative x never used for flight; optional Sandbox axes may show it as a guide only.
4. Generate bounded trajectory on fire/preview (debounce ~100ms, immediate revalidate on Fire). Cache by normalized IR, origin, board, allowlist version and sampler version. Same pure sampler and same polyline used for rendering and simulation. Error result typed, never throw through simulation. Preview may be hidden by level rules but validation always runs.

## Coordinates
World origin is bottom-left board edge; board W,H in units; cell center (c+0.5,r+0.5). Local `(u,v)=(worldX-originX, worldY-originY)`, `v=f(u)`, `u>=0`. Canvas `screenX=boardLeft+worldX*cellPx`, `screenY=boardTop+(H-worldY)*cellPx`; inverse exact. `cellPx=min(availableWidth/W,availableHeight/H)`; letterbox remaining space, no stretching. Campaign never draws Ox/Oy or persistent labels. Selected bird cell glows; hover/focus tile or enemy displays local coords to 0.1 cells, positive y upward; optional tutorial cell count hints fade. Sandbox may show axes via toggle. Natural square tiles are the grid. DPR affects rendering only. Resize does not change world state. Math 45° line must look 45°.

## Sampling and domain
MVP shot speed is constant horizontal units/sec, not constant arc speed; clearly document this. Sample monotone u, base step <=1/32 cell, adaptive midpoint and quarter samples if chord error >0.025 or segment length >0.20 cells; subdivide with bounded depth (8), total eval/sample budget (4096), minimum step 1/2048 cell. On unresolved discontinuity/steepness/nonfinite sample, stop at last verified continuous point, with visible termination marker; if too short reject shot. Clip segment at first board exit and never re-enter. Terminate at right edge, max u or max projectile lifetime. For denominator/log/sqrt/tan domain, detect sign/pole boundaries conservatively via interval checking of relevant subexpressions over each accepted segment; if interval cannot certify continuity subdivide or stop, even for otherwise valid functions. Implement bounded interval arithmetic for supported operators/functions or initially reject unsupported domain forms until their phase adds coverage. Never connect across known poles, sign changes or uncertified ranges. A finite-sample test alone cannot prove continuity of arbitrary formulas; clearly document conservative false rejects. Include `tan(x)`, `x/(x-2)`, `x/(x-2)^2` and `sqrt(1-x)-1` as regression cases. Preview polyline is the gameplay graph approximation, not a claim of exact real arithmetic.

## Flight and collision
Store immutable launch origin, sampled polyline, damage snapshot, elapsed horizontal distance, hit target ids. Each fixed step advance u by horizontalSpeed*dt; interpolate along same polyline. Sweep all traversed polyline segments (not only endpoint or chord across bends). Enemy circle hit test with snowball radius; moving targets use relative swept segment for same time interval, split by sample segment and interpolate enemy previous/current positions. Static obstacle AABB expanded conservatively or exact capsule-vs-box; choose and document geometry. Sort contacts by earliest time along step, tie obstacle before enemy then stable id. Apply shield rule from local segment direction, apply damage once per id, stop on obstacle or max hits; no hits beyond death/exit. Coordinate math is world-only; Phaser arcade gravity not used. Limit active projectiles, use broad-phase buckets when measurements justify. Preview illustrates path, not guaranteed future hit positions.

## Equivalence and quota
Normalize safe IR using deterministic bounded constant folding, sorted associative commutative operands, removal of neutral elements only when domain-preserving, simple like-term collection and polynomial coefficient representation for supported polynomial degree <=8. Do not simplify `x/x` to `1` (domain changes), `0*(1/x)` to `0`, or make unsafe sign identities. Use exact canonical string as key. Family classify from canonical structure: constant, linear, quadratic, polynomial-other, trig, rational, radical, exponential/log, mixed/other; precedence and allowed family set documented in code/test. `sin(x)-sin(x)` may be recognized as zero only with proven domain, otherwise mixed. Do not use general symbolic equivalence as a security promise. Bounded behavioral equivalence is required for quota-enabled levels (L5/L6): compare 65 fixed + 16 seed-derived u samples over common level-wide range [0,W], matching validity masks and finite values within absolute 1e-6 + relative 1e-6. Ignore nonfinite values only if both invalid; require >=16 finite comparisons. Compare direct to stable first representative (not transitive union); cap representatives 128; reject new bucket when cap reached unless matches existing. Exact key or match maps to existing bucket; collision/false-match caveat documented. Sampling uses level-wide u, not current bird position. UI communicates approximate matching; quota is game fairness, not anti-cheat. Family quota based on canonical family of representative; mixed family cap cannot be bypassed by obvious neutral terms. No claim of detecting all identities; include tests for `2x`, `x+x`, `2.0*x`, `x*2`, `sin(x)` vs `sin(x+2*pi)` (if supported) and domain mismatch. Use count-based registry, atomic fire and reset; deterministic order. Quota state persists across boss phases and relocation, cleared on retry/new level.

## Types (illustrative contract)
`FormulaResult = { ok: true; formula: ValidatedFormula } | { ok: false; code: FormulaError; messageKey: string }`; `SampleResult = { points: readonly Vec2[]; end: 'edge'|'domain'|'budget'|'range' }`; no function objects in save data. Error codes: EMPTY, TOO_LONG, SYNTAX, UNSUPPORTED, COMPLEXITY, ORIGIN, DOMAIN, NO_PATH, QUOTA, FAMILY_LOCK, COOLDOWN, NO_BIRD, CAPACITY, NOT_RUNNING. Keep formula grammar and error mapping shared, localized UI errors.
